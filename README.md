This GitHub profile **generates its own graphics**.

Instead of depending on external GitHub statistics services, the statistics displayed above are generated directly inside this repository.

```text
                    GitHub
                       │
                       ▼
              GitHub GraphQL API
                       │
                       ▼
              generate_stats.py
                       │
          ┌────────────┼────────────┐
          │            │            │
          ▼            ▼            ▼
      stats.svg    streak.svg   langs.svg
                                    │
                       ┌────────────┘
                       ▼
                   year.svg
                       │
                       ▼
                    README
```

The generator retrieves my public GitHub contribution and repository information through the **GitHub GraphQL API**.

It then converts that data into custom SVG graphics.

The generated graphics include:

```text
stats.svg
    └── yearly contributions
    └── active days
    └── best week
    └── contribution activity graph

streak.svg
    └── current contribution streak
    └── longest contribution streak

langs.svg
    └── languages by code size
    └── languages by repository count

year.svg
    └── character-based yearly contribution map
```

A scheduled **GitHub Actions** workflow runs the generator automatically.

```text
GitHub Actions
      │
      ▼
generate_stats.py
      │
      ▼
GitHub GraphQL API
      │
      ▼
Generate new SVGs
      │
      ▼
Anything changed?
      │
   ┌──┴──┐
   │     │
   NO   YES
   │     │
   ▼     ▼
  stop  commit
          │
          ▼
      git push
          │
          ▼
   Profile updated
```

So as my GitHub activity changes, the graphics on this profile change with it.

### The portrait generates itself too

The portrait at the top isn't a normal image embedded into the README.

My photograph is processed by a Python script and converted into an ASCII representation.

```text
portrait.jpg
      │
      ▼
background removal
      │
      ▼
grayscale conversion
      │
      ▼
bilateral filtering
      │
      ▼
contrast enhancement
      │
      ▼
brightness → ASCII characters
      │
      ▼
animated SVG
      │
      ▼
ascii.svg
```

The resulting characters are rendered as an SVG with a row-by-row typing animation.

The font is embedded directly inside the SVG so the character grid remains consistent across different systems and browsers.

Everything is stored directly in this repository.

**No third-party GitHub statistics service is required.**
